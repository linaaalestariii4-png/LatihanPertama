# LATIHAN JAVA — PERULANGAN DAN METHOD

## Deskripsi
Repository ini berisi tugas latihan pemrograman Java menggunakan Apache NetBeans dan Maven. Program dibuat untuk memahami penggunaan perulangan dan method dalam bahasa Java.

## Daftar Latihan

### 1. Latihan Pertama — Perulangan For
Menampilkan urutan barang dari 1 sampai 10, kemudian menampilkan urutan barang dari 10 sampai 1 menggunakan perulangan `for`.

### 2. Latihan Kedua — Perulangan While
Membuat simulasi stok barang yang dimulai dari 5 dan berkurang sampai 0 menggunakan perulangan `while`. Setelah stok habis, program menampilkan pesan "Stok habis".

### 3. Latihan Ketiga — Method Menghitung Kembalian
Membuat method `hitungKembalian()` untuk menghitung uang kembalian berdasarkan uang pembayaran dikurangi total harga barang.

### 4. Latihan Keempat — Method Menampilkan Daftar Barang
Membuat method `tampilkanDaftarBarang()` dengan tipe `void` untuk menampilkan nama barang sesuai jumlah pembelian.

## Teknologi yang Digunakan
- Bahasa pemrograman Java
